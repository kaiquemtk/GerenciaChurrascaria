# Gerência Churrascaria

Sistema para gerenciar uma churrascaria: funcionários, fornecedores, cargos e contas.

Projeto feito para a disciplina de Projeto de Software, dividido em 3 camadas (front-end, back-end e banco de dados).

## Tecnologias

- C# (Windows Forms)
- SQL Server

## Estrutura do projeto

- TCCTH - telas do sistema
- BLL - regras de negócio
- DAO - acesso ao banco de dados

## Funcionalidades

- Cadastro de funcionários (incluir, consultar, editar, excluir)
- Cadastro de fornecedores
- Cadastro de contas
- Cadastro de cargos
- Criação de usuários
